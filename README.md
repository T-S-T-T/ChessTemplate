# ChessTemplate

A modular chess base in Unity (2D, URP) built so rules, pieces, boards and presentation can be altered independently.

- Design: `Docs/GDD.md`
- Open questions and suggestions: `Docs/Questions.md`
- Project content lives under `Assets/_Project/`:
  - `Scripts/` Core, Rules, Pieces, Boards, Presets, AI, Input, UI, Persistence
  - `Data/` Pieces, Boards, Presets, Themes (rules and content as data)
  - `Art/`, `Audio/`, `Prefabs/`, `Scenes/`
  - `Tests/` EditMode (rules tests) and PlayMode

Status: notes and structure only, no code yet.
